# greentech-solutions
GreenTech Solutions is a startup focused on providing innovative, eco-friendly technology solutions to help businesses reduce their carbon footprint.

In this project I created a mock website for the client which focuses on eco-friendly and sustainability practices and products. I utilized a CSS stylesheet which focused on green, white and earthy tones to compliment the theme as well as using a modern UI approach that gave it the feel of a tech startup. This website uses some hover and transition effects on elements like the main logo, navigation bar, and product cards to make it more visually appealing. The main products that I listed were an energy monitor, smart recycling hub, and a carbon tracker. The resources page has a single blog-post page that could be scaled later to include more content depending on the needs of this client. It also features a Contact page which simulates entering a name, email and message and a confirmation message once submitted as well as a newsletter that an end-user can sign up for on the home page.

I used Firefox Responsive Design mode to ensure that the website is optimized for mobile though I admit that some improvements could be made to polish it even further, for the purpose of this project I think it can pass on most devices but it could be fixed up later by making some adjustments to the CSS stylesheet. I used the WAVE Web Accessibility Evaluation tool to make sure the website was within accessibility standards and all pages passed. Lastly, I used CodeChef online HTML/CSS Editor to view a live preview of my code while it was in progress which helped me to visualize different elements of the page and to limit the amount of commits to GitHub.
